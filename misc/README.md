# Miscellaneous

Дополнительные конфигурационные файлы.

## Файлы

### kbd67mkiirgbv3.layout.json
**Layout для механической клавиатуры KBD67 MKII RGB V3**

- Конфигурация раскладки клавиш
- Формат для VIA (клавиатурный конфигуратор)
- Кастомные маппинги и слои

**Использование:**
1. Открой VIA или другой совместимый конфигуратор
2. Импортируй `kbd67mkiirgbv3.layout.json`
3. Примени к клавиатуре

**Ссылки:**
- [VIA Configurator](https://www.caniusevia.com/)
- [KBD67 MKII RGB V3 на KBDfans](https://kbdfans.com/products/kbd67-mkii-rgb-v3)
